# 调研参考：画像字段与竞品维度

## 用户画像模板

```markdown
### [角色名]
- **组织/身份**：
- **JTBD**：
- **痛点**（按严重程度）：
- **现有替代方案**：
- **付费模式偏好**：
- **成功指标**：
- **关键场景路径**：（发现 → 试用 → 付费 → 留存）
- **与平台能力匹配**：训练 / 合成 / 市场 / 协作
```

## 竞品打分维度（1–5）

1. 克隆样本门槛与质量稳定性  
2. 情感与韵律可控性  
3. 多角色/项目管理（短剧）  
4. 音色 UGC 与市场/交易  
5. API、私有化、自托管  
6. 安全（水印、检测、审核、授权）  
7. 中文与跨语言  
8. 定价与单位经济  

## 合规检查项（中国语境）

- [ ] 克隆前明示同意与权属证明  
- [ ] 禁止未授权名人/他人声纹  
- [ ] 生成内容显著标识  
- [ ] 深度合成与生成式 AI 备案/评估（如适用）  
- [ ] 侵权投诉与下架 SLA
