# 需求分析参考

## REQ ID 命名

`REQ-{三位序号}`，域前缀可选：`REQ-V-012`（音色）、`REQ-M-008`（市场）、`REQ-S-003`（安全）

## 用户故事模板

```
As a [角色], I want [能力], so that [价值].
```

## 验收标准模板

```
Given [前置]
When [操作]
Then [可观测结果]
And [可选：性能/合规]
```

## MVP 裁剪原则

1. **Must**：注册 → 上传素材 → 训练音色 → 文本合成 → 导出音频  
2. **Should**：基础项目管理、手动情感标签  
3. **Could**：市场上架与交易、批量台词、自动情感  
4. **Won't (MVP)**：实时通话克隆、完整企业 SSO（除非用户指定 P0）

## 4 周 MVP-0 裁剪（总工期=4 周时）

| 保留 P0 | 延后 MVP+1 |
|---------|------------|
| 登录、授权书、训练、TTS、CSV 批量 | 三方实名、音色市场、购买凭证 |
| 项目/角色绑定、敏感词、显式标识 | 水印、指纹、情感滑杆、投诉工单 |
| 队列、基础配额 | 完整管理后台、自动提现 |

## 非功能示例指标

| 指标 | MVP 参考 |
|------|----------|
| 合成首包延迟 | P95 < 2s（流式） |
| 10min 素材训练 | 完成时间 + 队列可见 |
| 相似度 | 内测集 MOS/主观 AB，目标 ≥90% 需定义测评集 |
| 可用性 | 核心 API 99.5% |

## P0 合规验收示例

- 未上传「声纹授权声明」则训练 API 返回 403  
- 命中敏感词列表则合成请求拒绝并返回词条位置  
- 公开上架音色必须含授权类型字段（个人/商用）
