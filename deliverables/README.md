# 实训交付物目录

本目录对齐学校 **「项目序号_项目名称_交付物」** 包结构，用于答辩与结项提交。  
**研发正文**仍以 `docs/pm/`、`docs/requirements/`、`docs/architecture/` 的 Markdown 为准；此处以 Word 模板与填报物为主。

## 目录说明

| 目录 | 内容 |
|------|------|
| [01_项目立项](./01_项目立项/) | 项目启动报告（Project Start Report）`.doc` |
| [02_项目计划](./02_项目计划/) | 项目计划（简版）`.doc` |
| [03_需求规格](./03_需求规格/) | 需求规格说明书 `.doc`；调研报告见 `docs/research/` |
| [04_系统设计](./04_系统设计/) | 概要设计 SD_HLD `.doc`；详设见 `docs/architecture/` |
| [05_开发与交付](./05_开发与交付/) | 代码压缩包目录、用户手册模板；**源码即仓库根目录**，迁移脚本见 `infra/docker/migrations/` |
| [06_答辩阶段](./06_答辩阶段/) | 关闭报告模板、个人总结模板；PPT/录屏待补充 |
| [07_日常报告](./07_日常报告/) | 工作日志、实训个人周报（模板 + 已填版本） |

## 与仓库其他路径的关系

```
deliverables/          ← 本目录（对外提交 Word 包）
docs/pm/*.md           ← 立项/计划/需求分析 Markdown 源稿
docs/requirements/     ← 实现向 SRS 与子模块 A–G
docs/templates/word/   ← 开发用 Word 副本（命名带 03_ 前缀，与 01–04 内容对应）
scripts/fill_internship_reports.py  ← 可选：从模板批量填写 07 日常报告
```
