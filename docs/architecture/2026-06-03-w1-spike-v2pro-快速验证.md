# W1 Spike：GPT-SoVITS V2-PRO 快速验证

| 项 | 内容 |
|----|------|
| **目标** | 今天跑通：**预训练就绪 →（可选）微调 → 推理一句中文** |
| **引擎** | [GPT-SoVITS `20250606v2pro`](https://github.com/RVC-Boss/GPT-SoVITS/releases/tag/20250606v2pro) |
| **成功标准** | ① WebUI 或 CLI 能合成；② 记录 GPU/VRAM/耗时；③ 确认 v2Pro 权重齐全 |
| **非目标** | 自研 API、合规、CSV 批量（后续按架构文档迭代） |

> **Windows 说明**：官方推荐 **Linux + NVIDIA GPU**。Windows 本机可先验证仓库/权重/CPU 流程；**完整 GPU 训练推理建议 WSL2 或 Linux 云 GPU**。

## 3. 下载 v2Pro 预训练权重

目标目录：`GPT_SoVITS/pretrained_models/`

从 HuggingFace [lj1995/GPT-SoVITS](https://huggingface.co/lj1995/GPT-SoVITS/tree/main) 下载：

| 文件 | 用途 |
|------|------|
| `v2Pro/s2Dv2Pro.pth` | SoVITS 判别器 |
| `v2Pro/s2Gv2Pro.pth` | SoVITS 生成器 |
| `sv/pretrained_eres2netv2w24s4ep4.ckpt` | SV 模型 |
| `s1bert25hz-5k` 等 s1 相关 | GPT 阶段 **按 upstream 文档** |

可使用 huggingface-cli：

```powershell
pip install huggingface_hub
huggingface-cli download lj1995/GPT-SoVITS v2Pro/s2Gv2Pro.pth --local-dir GPT_SoVITS/pretrained_models
huggingface-cli download lj1995/GPT-SoVITS v2Pro/s2Dv2Pro.pth --local-dir GPT_SoVITS/pretrained_models
huggingface-cli download lj1995/GPT-SoVITS sv/pretrained_eres2netv2w24s4ep4.ckpt --local-dir GPT_SoVITS/pretrained_models
```

**Spike 检查**：启动 WebUI 前确认文件存在且无 0 字节。

## 4. 启动 WebUI（最快验证路径）

```powershell
cd GPT-SoVITS
python webui.py
```

浏览器打开终端提示的地址（通常 `http://127.0.0.1:9874`）。

### 4.1 验证步骤（UI 内）

1. **版本**：界面/设置中选择 **v2Pro** 相关模型路径（非 v3/v4）。
2. **零样本试听**（可选）：用 3–10s 参考音频 + 文本，先听相似度与速度。
3. **微调**（Spike 核心）：
   - 准备 **8–10 分钟中文干声**（无 BGM，32kHz/wav 更佳）
   - 走「数据预处理 → GPT 训练 → SoVITS 训练」向导
   - 记录：总耗时、峰值 VRAM、`nvidia-smi` 截图
4. **推理**：用微调后 checkpoint 合成 1–2 句短剧台词。

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| CUDA OOM | 减 batch；关闭其他占 GPU 程序；确认用 v2Pro 而非 Plus |
| 找不到 v2Pro 权重 | 检查 `pretrained_models` 路径与 WebUI 下拉配置 |
| Windows 原生报错 | 改用 **WSL2 Ubuntu** 或云 GPU 按同文档执行 |
| 合成电音/糊 | 检查素材 BGM；确认采样率；参考 Wiki 各版本特性 |
