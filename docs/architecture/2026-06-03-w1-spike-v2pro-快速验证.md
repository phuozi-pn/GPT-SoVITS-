# W1 Spike：GPT-SoVITS V2-PRO 快速验证

| 项 | 内容 |
|----|------|
| **目标** | 今天跑通：**预训练就绪 →（可选）微调 → 推理一句中文** |
| **引擎** | [GPT-SoVITS `20250606v2pro`](https://github.com/RVC-Boss/GPT-SoVITS/releases/tag/20250606v2pro) |
| **成功标准** | ① WebUI 或 CLI 能合成；② 记录 GPU/VRAM/耗时；③ 确认 v2Pro 权重齐全 |
| **非目标** | 自研 API、合规、CSV 批量（后续按架构文档迭代） |

> **状态（2026-06-03）**：✅ 零样本 · ✅ 微调 4+4 · ✅ 9880 试听链路。

> **2026-06 起推荐**：日常微调请用 **[云端 GPU 训练指南](./2026-06-10-云端GPU训练指南.md)**；本文保留引擎验证与历史 Docker Spike 细节。

## 4. 启动 WebUI（最快验证路径）


### 4.1 验证步骤（UI 内）

1. **版本**：界面/设置中选择 **v2Pro** 相关模型路径（非 v3/v4）。
2. **零样本试听**（可选）：用 3–10s 参考音频 + 文本，先听相似度与速度。
3. **微调**（Spike 延伸，非零样本必需）：
   - 准备 **8–10 分钟中文干声**（无 BGM，32kHz/wav 更佳）
   - 走「数据预处理 → GPT 训练 → SoVITS 训练」向导
   - 记录：总耗时、峰值 VRAM、`nvidia-smi` 截图
4. **推理**：用微调后 checkpoint 合成 1–2 句短剧台词。

### 4.6 VRAM 采样说明

**命令**（训练另开终端，2s 轮询）：

```powershell

```

**本次记录**（`-FromStep sovits`，5080 Laptop 16GB，`is_half=true`）：

| 指标 | 值 |
|------|-----|
| 峰值 `memory.used` | **6596 MiB** |
| 总显存 | 16303 MiB |
| 占用率 | ~40% |
| 次高峰 | 4770 / 4216 / 3896 MiB（epoch  ramp） |
| 空闲基线 | ~1904–1924 MiB |

> 单条 ~7s 参考音频 + 4 epoch SoVITS 的 Spike 显著低于架构估的「~12GB」生产训练预算；8–10min 素材 + 更高 epoch 需 W2 再测。

### 4.7 微调后听感（9880）

**前提**：容器内 **`api_v2` 必须在跑**；映射 9880 ≠ 服务已启动。

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\engine_api_v2.ps1 -Action status    # 看是否已起
.\scripts\engine_api_v2.ps1 -Action start     # 未起则后台启动（~1-2 min）
.\scripts\engine_api_v2.ps1 -Action synthesize  # 切微调权重 + 输出 finetuned_spike.wav
```

手动等价：先 `set_gpt_weights` + `set_sovits_weights`（**两者都要**，yaml 默认 SoVITS 可能是底模），再 `GET /tts`；PowerShell 需 `-TimeoutSec 300`。

**常见误判**：

| 报错 | 含义 |
|------|------|
| 连接被意外关闭 | 9880 **无进程** → `-Action start` |
| `address already in use` | **已有** api_v2 → 勿再 `python api_v2.py`；用 status 或 `-Action stop` 后重启 |

## 8. Spike 环境 Workaround（本机实测）

### 8.1 推理 / Docker 启动

| 现象 | 处理 |
|------|------|
| WebUI `unhashable type: 'dict'` | 容器内 `pip install 'starlette<1.0.0'` 后再启 `webui.py` |
| 9872 `ERR_EMPTY_RESPONSE` / 推理进程秒退 | 英文界面下 GPT 下拉值为显示名；需在 `inference_webui.py` 用 `name2gpt_path` 解析（已 patch `_resolve_pretrained_path`） |
| 合成报「错误」、`libtorchcodec` / FFmpeg | `torchaudio.load` 失败；已 patch `safe_load_audio()` / `safe_torchaudio_load()` 回退 `soundfile` |
| Windows `/dev/null` volume | 删除 compose 中对应行 |
| Lite `undefined volume tools/asr/models` | compose **去掉** asr/uvr5 挂载；坏联接点 `rmdir` 后 `mkdir` |
| UVR5 `uvr5_weights` 不存在 | 零样本可忽略；人声分离才需要 |
| 9880 **连接被意外关闭** | 端口已映射但 **`api_v2` 未启动** → `scripts/engine_api_v2.ps1 -Action start` |
| 9880 **`address already in use`** | 容器内 **已有** `api_v2`（含 `docker exec -d` 后台）→ 勿重复启；`status` / `stop` |
| `docker compose run` 端口冲突 | **已有一个**引擎容器占 9874 → 复用 `docker exec`，或 `engine_docker_cleanup.ps1 -StopStale` |

### 8.2 微调 Spike（`spike_train_v2pro.py`）

| 现象 | 处理 |
|------|------|
| `No module named 'text'` | 设置 `PYTHONPATH`（对齐 WebUI）；Spike 脚本已内置 |
| `No module named 'text'` + `-s` | 勿对 prepare 脚本加 `-s`；已移除 |
| 1B-sv `libtorchcodec` | 自动 patch `2-get-sv.py` → `safe_torchaudio_load`（`patches/apply_train_torchaudio_patch.sh`） |
| GPT 缺 `6-name2semantic.tsv` | WebUI 会合并 `6-name2semantic-0.tsv`；Spike 已补 1A/1C 合并 |
| SoVITS 保存 `G_*.pth` FileNotFoundError | 训练前 `mkdir logs_s2_v2Pro`；Spike 已补 |
| GPT resume / `weights_only` / `PosixPath` | 勿全量重跑；`-FromStep sovits` 续跑；全量 GPT 前清空 `logs_s1_*/ckpt` |
| PowerShell `docker exec` here-string 语法错误 | 用 `bash prepare_spike_samples.sh`，勿 inline `-lc` 多行 |

> 推理 patch 在上游 `inference_webui.py` / `tools/my_utils.py`；微调 patch 由本产品 `infra/engine/patches/` 在 Spike 启动时 idempotent 应用。**勿提交到本产品仓库**；Worker 镜像构建时应固化等价修复。

完整清单：[infra/engine/WINDOWS-DOCKER-PATCHES.md](../../infra/engine/WINDOWS-DOCKER-PATCHES.md)
