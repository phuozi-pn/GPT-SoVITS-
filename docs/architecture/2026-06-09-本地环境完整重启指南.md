# 本地环境完整重启指南

本机用途：**平台 API + Web 工作台 + 引擎 9880 合成**。  
**微调训练在云端 GPU**，见 [云端 GPU 训练指南](./2026-06-10-云端GPU训练指南.md)。

## 一、全部关掉

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\platform_stop.ps1
.\scripts\engine_api_v2.ps1 -Action stop
```

## 二、一键重启平台

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\dev_restart.ps1 -Background
```

## 三、Web 工作台（另开终端）

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\web_dev.ps1
```

浏览器：**http://127.0.0.1:5173**

## 四、引擎 9880（合成用，可选）

在上游 `GPT-SoVITS` 目录用 Docker 起 Lite 容器（见 [infra/engine/README.md](../../infra/engine/README.md) §4），然后：

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\engine_api_v2.ps1 -Action start   # 自动 sync .env 容器名
.\scripts\engine_api_v2.ps1 -Action status
```

## 五、检查清单

| 检查 | 命令 / URL |
|------|------------|
| 平台 | `.\scripts\platform_status.ps1` |
| API | http://127.0.0.1:8001/health |
| 9880 | `.\scripts\engine_api_v2.ps1 -Action status` |

## 六、训练权重

在 AutoDL / 租 GPU 上跑 [cloud/train.sh](../../infra/engine/cloud/train.sh)，权重 scp 回本机后按 [自己素材训练试听指南](./2026-06-09-自己素材训练试听指南.md) 试听。
