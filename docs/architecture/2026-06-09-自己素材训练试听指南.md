## 1 前置

- 云端已训练并 scp 权重到 `GPT-SOVITS/GPT_weights_v2Pro/`、`SoVITS_weights_v2Pro/`
- 本机引擎 9880 可用：`.\scripts\engine_api_v2.ps1 -Action status`

## 2 参考音频

- 从云端 `dataset/segments/` 选 **3–10 秒** 片段
- `prompt_text` 必须与 ref wav 内容一致（用 `train.list` 对应行）

## 3 合成

```powershell
cd C:\Users\panta\Desktop\GPT
.\scripts\engine_api_v2.ps1 -Action synthesize `
  -Text "你好，这是训练后的试听。" `
  -GptWeights "GPT_weights_v2Pro/your_exp-e4.ckpt" `
  -SovitsWeights "SoVITS_weights_v2Pro/your_exp_e4_s100.pth" `
  -RefWav "C:\path\to\ref_6s.wav" `
  -PromptText "与 ref 一致的句子"
```

## 4 听感排查

| 现象 | 可能原因 |
|------|----------|
| 乱码 / 不像人话 | 训练时音文未对齐；回云端重跑 `prepare_train_dataset` |
| api_v2 报错 | ref 不在 3–10s；权重路径错误 |
| 完全不像 | epoch 太少或素材质量差 |
