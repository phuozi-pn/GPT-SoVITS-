# 云端 GPU 训练指南

| 日期 | 2026-06-10 |
|------|------------|
| 状态 | **推荐路径**（AutoDL / 租 GPU 服务器） |

## 1 分工

| 环节 | 位置 | 说明 |
|------|------|------|
| 素材准备 | 本机 | 转 **wav**、干声 8–10 分钟 |
| 切分 + ASR + 微调 | **云端 GPU** | Linux + CUDA，不用 Windows Docker 训练 |
| 下载权重 | scp | `.ckpt` + `.pth` |
| 合成试听 | 本机 | 引擎 **9880** api_v2 |

平台 API 的 `POST /train`（Train Worker）默认 **`TRAIN_MOCK=true`**，本阶段**不在本机跑微调**。

---

## 2 素材要求

| 项 | 要求 |
|----|------|
| 格式 | wav，16kHz+，单声道优先 |
| 时长 | 8–10 分钟干声（无 BGM、无混响） |
| 对齐 | 长音频**必须**走「静音切分 + FunASR」，不要手工按时间切 + 整段 ref 均分 |

---

## 3 云端环境（AutoDL 示例）

### 3.1 选实例

- GPU：RTX 4090 / A100 等，显存 ≥ 16GB
- 镜像：PyTorch + CUDA（与 GPT-SoVITS 兼容即可）
- **无需 Docker**（直装 Python 更简单）

### 3.2 克隆引擎 + 平台脚本

```bash
cd ~
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS && git checkout 20250606v2pro

# 平台仓库（仅需 infra/engine 脚本；也可整仓 clone）
git clone <你的 GPT 仓库地址> GPT
export ENGINE_ROOT=$HOME/GPT-SoVITS
export PLATFORM_ROOT=$HOME/GPT
```

### 3.3 预训练权重

放到 `GPT-SoVITS/GPT_SoVITS/pretrained_models/`（v2Pro：`s2Gv2Pro.pth`、`s2Dv2Pro.pth`、`s1v3.ckpt`、`sv/…` 等）。  
国内可用镜像 / 魔搭 wget（与 [W1 Spike](./2026-06-03-w1-spike-v2pro-快速验证.md) 一致）。

### 3.4 Python 依赖

```bash
cd $ENGINE_ROOT
pip install -r requirements.txt
pip install opencc funasr modelscope
# 系统 ffmpeg（AutoDL 通常已有）
ffmpeg -version
```

**1B-sv 补丁**（torchaudio 加载失败时）：

```bash
bash $PLATFORM_ROOT/infra/engine/patches/apply_train_torchaudio_patch.sh
```

**G2PW**（中文预处理报错时）：按 Spike 文档从魔搭下载 `G2PWModel` 到引擎约定目录。

### 3.5 上传训练 wav

```powershell
# 本机 PowerShell
scp -P <端口> C:\Users\...\train_10min.wav root@<主机>:/root/train_10min.wav
```

## 4 训练（云端一条命令）

```bash
cd $PLATFORM_ROOT
bash infra/engine/cloud/train.sh /root/train_10min.wav /root/train_out my-voice-001
```

脚本顺序：

1. `prepare_train_dataset.py` — 静音切分 + FunASR → `train.list`
2. `spike_train_v2pro.py` — 1A–1C 预处理 + GPT/SoVITS 微调（默认 4+4 epoch）

检查对齐（**必做**）：

```bash
head -5 /root/train_out/dataset/train.list
# 随机听 segments/*.wav，确认文字与发音一致
```

## 6 本机合成试听

### 6.1 起引擎 9880

```powershell
cd C:\Users\panta\Desktop\GPT
# 在上游 GPT-SoVITS 目录用 docker compose 起 Lite 容器后：
.\scripts\engine_api_v2.ps1 -Action start
.\scripts\engine_api_v2.ps1 -Action status
```

### 6.2 参考音频（3–10 秒）

从 `train_out/dataset/segments/` 挑一段 **3–10 秒** 的 wav，文本用 `train.list` 里对应句（或 ASR 句）。  
过长参考会导致 api_v2 报错。

### 6.3 合成

```powershell
.\scripts\engine_api_v2.ps1 -Action synthesize `
  -Text "你好，这是云端训练后的试听测试。" `
  -GptWeights "GPT_weights_v2Pro/cloud_my-voice-001-e4.ckpt" `
  -SovitsWeights "SoVITS_weights_v2Pro/cloud_my-voice-001_e4_s100.pth" `
  -RefWav "C:\path\to\ref_6s.wav" `
  -PromptText "与 ref  wav 一致的句子"
```

金标准对照：用 `infra/engine/samples/ref_zh_zero_shot.wav` 合成正常 → 引擎 OK，问题在权重/参考对齐。

## 7 常见问题

| 现象 | 处理 |
|------|------|
| 合成乱码 / 不像人话 | `train.list` 音文不对齐；重跑 prepare，听 segment 抽查 |
| `ModuleNotFoundError: ffmpeg` | 在**云端**装依赖，不要用 Windows 系统 Python 跑 prepare |
| 1B-sv / torchaudio | 打补丁脚本；确认 `ffmpeg` CLI 可用 |
| 本机 `No such container` | 训练不依赖本机 Docker；仅合成需要引擎容器 |
| epoch 太少音色不像 | 改 `infra/engine/train-v2pro-spike.json` 增大 `gpt_epochs` / `sovits_epochs` |
