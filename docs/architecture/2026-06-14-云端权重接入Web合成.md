# 云端权重接入 Web 合成

训练完成后，将本机 `GPT-SOVITS` 目录下的权重注册到平台，即可在 **音色库** 页面合成。

## 前提

- 平台已启动：`.\scripts\dev_restart.ps1 -Background`
- 引擎 9880：`.\scripts\engine_api_v2.ps1 -Action start`
- `.env` 中 `ENGINE_MOCK=false`，`ENGINE_TRAIN_ROOT` 指向本机 GPT-SoVITS

## 方式 1：Web 音色库

1. 打开 http://127.0.0.1:5173/library
2. 填写权重相对路径、ref wav 本机路径、ref 文本
3. 点击 **导入到平台**
4. 在 **快速合成** 选版本试听

## 方式 2：命令行

```powershell
cd C:\Users\panta\Desktop\GPT
.\.venv\Scripts\python.exe scripts\import_engine_weights.py `
  --gpt "GPT_weights_v2Pro/cloud_guzhenren-004-e8.ckpt" `
  --sovits "SoVITS_weights_v2Pro/cloud_guzhenren-004_e8_s400.pth" `
  --ref "C:\Users\panta\Desktop\ref_guzhenren.wav"
```

`DEV_SKIP_AUTH=true` 时可不传 token。

## 004 推荐参数

| 字段 | 值 |
|------|-----|
| GPT | `GPT_weights_v2Pro/cloud_guzhenren-004-e8.ckpt` |
| SoVITS | `SoVITS_weights_v2Pro/cloud_guzhenren-004_e8_s400.pth` |
| ref | `ref_guzhenren.wav`（3–10s） |
| ref_text | 与 ref 音频一致 |
| text_split_method | `cut0`（语气更稳） |

## 批量配音

见 **批量配音** 页（/projects）：创建项目 → 绑定角色 → 上传 CSV。

CSV 格式：

```csv
role,text
龙宫,方源，你给我出来！
龙宫,你们用不了宿命骨。
```

导出 ZIP：`/{角色名}/{序号}_{角色名}.wav`
