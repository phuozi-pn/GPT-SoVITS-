# W3 合规（敏感词 + 显式标识导出）

## 敏感词

- 词表：`infra/compliance/sensitive_words.txt`（每行一词，`#` 为注释）
- 环境变量：`COMPLIANCE_WORDLIST_PATH`（可选，覆盖默认路径）
- 单条合成：提交前拦截，返回 `SENSITIVE_WORD`
- CSV 批量：**行级**拦截，命中行失败，其余继续合成

## 合规导出（REQ-010）

- 所有对外下载走 `GET /api/v1/exports/{job_id}/download`
- 单条 wav：Worker 在音频前拼接「短-长-短-短」节奏标识
- 批量 ZIP 含：
  - `COMPLIANCE_README.txt`
  - `manifest.json`
  - `{角色}/{序号}_{角色}.wav`（每条已含标识）

## Web

- 音色库：须勾选 AI 告知后才能合成；下载用「合规导出下载」
- 批量配音：完成后点「合规 ZIP 下载」

## 配置（.env）

```
COMPLIANCE_LABEL_TYPE=rhythm
COMPLIANCE_EXPORT_REQUIRED=true
```
