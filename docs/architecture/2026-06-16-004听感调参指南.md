## 3. 换 ref（情绪）

`ref_text` 必须与 ref 音频内容一致，否则音质会崩。

```powershell
# 从 train_20min 截取 8s（需人工核对 ref_text）
.\.venv\Scripts\python.exe scripts\extract_ref_clip.py data\train_raw\train_20min.wav --start-sec 120 --duration-sec 8

$env:REF_WAV="data\tune_refs\train_20min_120s.wav"
$env:REF_TEXT="（填与音频一致的句子）"
.\.venv\Scripts\python.exe scripts\tune_ab_compare.py
```

愤怒/命令类台词：优先试素材里 **情绪更匹配** 的 ref 片段（云端 segments #4、#26 若有 ASR 文本最佳）。

**听感 A/B 选定（2026-06-16）**：`cut0_t078_sp105` → 已写入 Web/导入默认值，并对已有导入版本执行 `scripts/apply_tune_preset.py --all-imported`。
