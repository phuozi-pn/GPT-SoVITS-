# 新机器快速部署（约 30 分钟）

在 **Windows** 上从零搭本地开发/内测环境。

> **完整步骤（推荐）**：[从零安装指南.md](../从零安装指南.md) — 含软件下载、Mock/真合成、排障。  
> 所有命令在仓库根目录 `GPT/` 下执行。

## 速查

```powershell
git clone https://github.com/phuozi-pn/GPT-SoVITS-.git GPT
cd GPT
python -m venv .venv && .\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env
.\scripts\dev_restart.ps1 -Background    # 终端 1，需 Docker Desktop
.\scripts\web_dev.ps1                    # 终端 2 → http://127.0.0.1:5173
```

## 可选：真实合成 9880
