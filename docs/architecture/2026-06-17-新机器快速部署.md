# 新机器快速部署（约 30 分钟）

在 **Windows** 上从零搭本地开发/内测环境。

> 所有命令在仓库根目录 `GPT/` 下执行，不要在 `Desktop/` 下。

## 0. 前置

| 依赖 | 版本 |
|------|------|
| Python | 3.12+ |
| Node.js | 20+ |
| Docker Desktop | PG + Redis |
| GPT-SoVITS 引擎 | 上游 clone（合成 9880，可选） |

## 1. 克隆与 Python 环境（5 min）

```powershell
git clone git@github.com:phuozi-pn/GPT-SoVITS-.git GPT
cd GPT

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
copy .env.example .env
```

编辑 `.env` 关键项：

```ini
ENGINE_MOCK=false
ENGINE_TRAIN_ROOT=C:/Users/you/Desktop/GPT-SOVITS/GPT-SoVITS
DEV_SKIP_AUTH=true
QUOTA_MONTHLY_TRAIN_LIMIT=99
```

## 2. 平台 API + Worker（5 min）

```powershell
.\scripts\dev_restart.ps1 -Background
.\scripts\platform_status.ps1
```

应看到 `api` / `train` / `infer` / `batch` 均为 running，API health 200。

## 3. Web 前端（3 min）

```powershell
.\scripts\web_dev.ps1
```

打开 http://127.0.0.1:5173/studio

## 4. 引擎 9880（10 min，可选）

在上游 `GPT-SoVITS` 目录启动 Docker Lite 后：

```powershell
.\scripts\engine_api_v2.ps1 -Action start
.\scripts\engine_api_v2.ps1 -Action status
```

## 5. 导入云端权重 + 试听（5 min）

```powershell
.\.venv\Scripts\python.exe scripts\import_engine_weights.py
.\.venv\Scripts\python.exe scripts\apply_tune_preset.py --all-imported
```

Web → **音色库** → 合成试听。

## 6. 冒烟验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\smoke_e2e_guzhenren.py
```

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 脚本找不到 | `cd` 到 `GPT/` 再运行 |
| 合成失败 | 9880 未启动或 `ENGINE_MOCK=true` |
| 批量无 ZIP | `batch` worker 未运行 → `dev_restart -Background` |
| 迁移失败 | Docker 中 PG 是否 healthy |
