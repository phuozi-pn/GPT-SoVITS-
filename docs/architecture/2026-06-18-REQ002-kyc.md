# REQ-002 训练前实名认证

> 状态：**MVP+1 第四切片（mock 核验 + 运营人工通过 + 训练门禁）**

## 能力

| 能力 | API / 页面 | 说明 |
|------|------------|------|
| 查询状态 | `GET /api/v1/kyc/status` | `verified` / `required` |
| 提交核验 | `POST /api/v1/kyc/submit` | `KYC_MOCK=true` 时格式+成年校验即通过 |
| 训练门禁 | `POST /voices/{id}/train` | 未实名 → `403 KYC_REQUIRED` |
| 运营人工 | `POST /admin/kyc/{user_id}/verify` | 邀请制人工通过 |
| 待审列表 | `GET /admin/kyc/pending` | 运营台展示 |
| 审计 | `kyc_audit_logs` 表 | 仅存掩码姓名、身份证后四位与 hash |
| Web | `/kyc` | 工作台步骤 ③ 前引导 |

## 配置

```env
KYC_REQUIRED=true
KYC_MOCK=true
```

`KYC_MOCK=false` 且无三方服务商时提交返回 `503 KYC_PROVIDER_UNAVAILABLE`，可走运营人工 verify。
