# REQ-030 对外 Open API

> 状态：**API Key + 开放合成/任务查询**

## 能力

| 能力 | API | 认证 |
|------|-----|------|
| 创建密钥 | `POST /developer/api-keys` | Bearer / 开发 `X-User-Id` |
| 列出密钥 | `GET /developer/api-keys` | 同上（仅前缀，不回显完整 key） |
| 撤销密钥 | `DELETE /developer/api-keys/{id}` | 同上 |
| 开放合成 | `POST /open/synthesis` | `X-Api-Key: vsk_...` |
| 查询任务 | `GET /open/jobs/{id}` | `X-Api-Key` |

默认 scopes：`synthesis:write`、`jobs:read`。

开放合成与 Web 合成共用合规、配额、授权校验逻辑。

## 示例

```bash
# 创建密钥（登录后）
curl -X POST http://localhost:8001/api/v1/developer/api-keys \
  -H "X-User-Id: $USER" -H "Content-Type: application/json" \
  -d '{"name":"my-integration"}'

# 合成
curl -X POST http://localhost:8001/api/v1/open/synthesis \
  -H "X-Api-Key: vsk_xxxx" -H "Content-Type: application/json" \
  -d '{"voice_version_id":"...","text":"你好"}'

# 轮询
curl http://localhost:8001/api/v1/open/jobs/{job_id} -H "X-Api-Key: vsk_xxxx"
```
