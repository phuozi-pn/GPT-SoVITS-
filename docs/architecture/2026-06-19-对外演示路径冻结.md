# 对外演示路径冻结

版本：v1.0 · 2026-06-19  
状态：**冻结**（MVP 对外演示仅以下三条）

## 为何冻结

代码库已含 KYC、结算、开放 API、社区、支付 mock 等 **MVP+2** 能力。对外演示若全部露出，故事会散、验收困难。本文冻结 **3 条金路径**，其余标为 **Labs**。

## 冻结的三条用户故事

| ID | 角色 | 目标 | 关键路由 |
|----|------|------|----------|
| `visitor` | 访客 | 听懂产品并试听 | `/` → `/browse` → `/login` |
| `buyer` | 买家 | 购买授权并合成、验真 | `/catalog` → `/library` → `/verify/:id` |
| `creator` | 创作者 | 训练并上架、发动态 | `/studio` → `/catalog` → `/discover/feed` |

### 访客：试听选音

1. 打开首页 `/`，查看平台指标与精选试听  
2. 进入 `/browse?pick=` 试听样音  
3. 可选：`/updates` 浏览公开动态；`/creator/:id` 创作者主页  
4. 点击「登录」进入工作台

### 买家：授权与合成

1. 登录后 `/catalog` 试听并购买授权  
2. `/library` 选音色合成返听  
3. 下载 PDF 凭证，访问 `/verify/:authorizationId` 验真  
4. `/community` 私信卖家洽谈（可选）

### 创作者：训练上架

1. `/studio` 完成授权上传与训练（KYC 门禁保留）  
2. `/catalog` 发布到音色馆  
3. `/discover/feed` 发帖；买家从 `/community` 私信

## Labs（默认隐藏）

设环境变量 `VITE_LABS=1` 后可在前端露出以下入口：

| 能力 | 说明 | 入口 |
|------|------|------|
| 卖家钱包 / 提现 | 结算 mock | 音色馆 → 卖家钱包 |
| 支付订单审计 | 运营 mock | 运营台 → 支付订单 |
| 开放 API / 开发者密钥 | 后端已有 | API 文档（无独立 Web 页） |

未列于上表但已在 repo 的域（KYC、质量评测、Batch 等）**不隐藏**——它们是冻结路径的依赖，但不单独对外叙事。

## 工程落点

- 前端开关：`apps/web/src/config/features.ts` → `isLabsEnabled()`  
- 路由 Labs：`meta.labs` + `LABS_ROUTE_NAMES`  
- E2E：`apps/web/e2e/golden-paths.spec.ts`（展示站 + 购买合成）  
- E2E：`apps/web/e2e/social-verify.spec.ts`（社区发帖 + 结账验真）  
- E2E 基建：`scripts/e2e_start_api.py`（Windows）/ `e2e_start_api.sh`（Linux）、`infra/docker/migrations/020_e2e_catalog_seed.sql`  
- Auth 审计：`tests/test_auth_viewer_boundary.py`
