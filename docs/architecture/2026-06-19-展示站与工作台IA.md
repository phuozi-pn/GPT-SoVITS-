# 展示站与工作台 · 信息架构

> **注意**：壳层已于 2026-06-19 重构为 `public` / `workbench` / `bare` 三分支，详见 [Web 模块化 IA 重构](./2026-06-19-web-frontend-modular-ia.md)。下文 `ShowcaseLayout` 描述已过时，保留作历史参考。

版本：v1.0 · 2026-06-19

## 双壳模型

| 壳 | 布局组件 | 受众 | 典型路由 |
|----|----------|------|----------|
| **展示站** | `ShowcaseLayout` | 访客；已登录也可浏览 | `/` `/browse` `/updates` `/login` `/verify/:id` `/creator/:id`（访客） |
| **工作台** | `AppLayout` | 已登录用户 | `/library` `/studio` `/catalog` `/discover/*` `/community` |

判定逻辑：`useAppShell()` — `meta.layout === 'showcase'` 或 (`meta.public` 且未登录)。

## 导航层级（工作台仅一层上下文）

```
AppTopBar     → 分组 / 页面名 + workflow 一句（唯一主上下文）
侧栏分组       → 制作 / 音色 / 社区
SocialSubNav  → 发现子 Tab（动态 | 精选 | 指南）+ 消息
页面内         → 不再重复 PageHero hint（发现模块已去掉顶层 Hero）
```

**禁止**在音色馆、训练台同时堆叠：顶栏 workflow + PageHero 长 hint + 侧栏 hint。

## 展示站导航

```
ShowcaseLayout 顶栏：首页 | 音色馆 | 动态
页脚：音色馆 · 社区动态 · 登录/工作台
```

### 品牌区行为

| 状态 | 点击 VS 品牌 |
|------|----------------|
| 访客 | `/` 首页 |
| 已登录 | `/` 首页（页内横幅可进工作台） |

侧栏底部 **首页** / **公开站点** 为次要出口，视觉降权（小字号、无位移 hover）。

## 公开页组件约定

| 组件 | 用途 |
|------|------|
| `ShowcasePageHead` | 标题 + hint + actions |
| `PageMetrics` | 行内指标 `精选 **3** · 公开 **12**` |
| `ShareLink` | 复制当前页 URL |

样式见 `apps/web/src/styles/showcase.css`；Token 见《复古录音室页面规范》§2–3。
