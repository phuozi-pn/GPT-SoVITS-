# 生产部署 · 认证硬失败清单

版本：2026-06-19  
适用范围：API（`apps/api`）生产 / staging 环境

## 必须项

| 环境变量 | 生产值 | 说明 |
|----------|--------|------|
| `DEV_SKIP_AUTH` | **未设置或 `0`** | 若为 `1`，匿名请求会落到开发用户，**禁止**上生产 |
| `JWT_SECRET` | 强随机密钥 | 与签发 token 一致 |

部署脚本 / CI 应在启动前断言：

```python
if os.getenv("ENV", "").lower() in ("production", "staging"):
    assert os.getenv("DEV_SKIP_AUTH", "0") != "1", "DEV_SKIP_AUTH must be off in prod"
```

## 匿名可读（GET）

以下接口允许无 Bearer token（`VIEWER_ANONYMOUS`）：

- `GET /api/v1/catalog` — 公开音色馆列表
- `GET /api/v1/community/feed` — 公开动态流
- `GET /api/v1/quality/verify/{id}` — 授权验真（只读）

## 必须登录（写 / 私有读）

所有 **POST / PUT / PATCH / DELETE** 及私信、购买、合成、发帖等，须 `get_current_user_id`：

- 社区发帖、点赞
- 私信 `/api/v1/messages`
- 音色馆购买、上架、授权
- 合成、导出、训练任务

回归测试：`tests/test_auth_viewer_boundary.py`

## 前端

- Token 存 `localStorage`（商用前评估 httpOnly cookie + CSRF，见 ADR 待办）
- 生产构建 **勿** 设置 `VITE_LABS=1`（运营台等 Labs 路由默认隐藏）

## 验收

1. 无 `Authorization` 调用写接口 → **401**
2. 无 token 访问 `/library` → 前端跳转 `/login`
3. `DEV_SKIP_AUTH=0` 时无 `X-User-Id` 捷径
