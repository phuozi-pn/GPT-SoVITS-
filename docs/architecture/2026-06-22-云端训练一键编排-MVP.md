# 云端训练一键编排（MVP）

> v1.0 · 2026-06-22 · 状态：MVP 已实现（SSH 编排 + Studio 选项）

## 目标

用户只需准备干声音频并配置远端 GPU 连接，平台自动完成：

1. 本机转码为 wav（上传阶段已有）
2. SCP 上传至云端工作目录
3. 远端执行 `infra/engine/cloud/train.sh`（切分 + FunASR 对齐 + v2Pro 微调）
4. 拉回 `.ckpt` / `.pth` 至本机 `ENGINE_TRAIN_ROOT`
5. 注册 `VoiceVersion`，合成走完整微调权重

## 与「快速克隆」对比

| 维度 | 快速克隆 (`quick`) | 云端完整微调 (`cloud`) |
|------|-------------------|------------------------|
| GPU | 不需要 | 远端租用 GPU |
| 训练 | 无，zero-shot 参考 | 4+4 epoch 默认 spike |
| 音质 | 短参考、歌词泄漏风险 | 接近蛊真人等完整微调效果 |
| 耗时 | 秒级 | 数十分钟 |
| 本机要求 | `ENGINE_MOCK=false` + 9880 | 另需 `ENGINE_TRAIN_ROOT` 存权重 |

## 配置（管理员 `.env`）

```env
TRAIN_MOCK=false
ENGINE_TRAIN_ROOT=C:/Users/you/GPT-SOVITS/GPT-SoVITS
ENGINE_MOCK=false

CLOUD_TRAIN_ENABLED=true
CLOUD_TRAIN_SSH_HOST=connect.autodl.xyz
CLOUD_TRAIN_SSH_PORT=12345
CLOUD_TRAIN_SSH_USER=root
CLOUD_TRAIN_SSH_KEY_PATH=C:/Users/you/.ssh/id_ed25519
CLOUD_TRAIN_REMOTE_ENGINE_ROOT=/root/GPT-SoVITS
CLOUD_TRAIN_REMOTE_PLATFORM_ROOT=/root/GPT
CLOUD_TRAIN_REMOTE_WORK_DIR=/root/cloud_train_jobs
CLOUD_TRAIN_SSH_TIMEOUT_SEC=7200
```

远端需预先：

- 克隆 GPT-SoVITS 至 `CLOUD_TRAIN_REMOTE_ENGINE_ROOT`
- 克隆本平台仓库至 `CLOUD_TRAIN_REMOTE_PLATFORM_ROOT`（含 `infra/engine/cloud/train.sh`）
- Python 环境 + FunASR + CUDA（见 [云端 GPU 训练指南](./2026-06-10-云端GPU训练指南.md)）

## API

- `GET /api/v1/platform/capabilities` → `cloud_train_available` / `cloud_train_user_connected`
- `GET|PUT|DELETE /api/v1/cloud-gpu/profile` — 用户自有 SSH 凭证（加密存储）
- `POST /api/v1/cloud-gpu/profile/test` — 连接与远端环境检查
- `POST /api/v1/voices/{id}/train` body 可选 `train_backend: "cloud"`

Worker 按 job `hyperparams.train_backend` 或全局 `TRAIN_MODE=cloud` 选择 `CloudTrainAdapter`；自服务路径仅需用户 profile，不依赖全局 `CLOUD_TRAIN_SSH_HOST`。

## 两条完整微调路径（v1.1）

与 **快速克隆** 分离：Studio 步骤 ③ 三选一，互不影响。云端 / 权重未配置时，快速克隆仍可独立完成试听。

### A. 云端一键编排（本机预处理 dataset）

Studio 选「云端完整微调」→ 本机 **切分 + ASR 对齐**（faster-whisper）→ 只上传 `segments/` + `train.list` → 远端仅跑 spike 训练 → 拉回权重。

默认 `CLOUD_TRAIN_LOCAL_DATASET_PREP=true`；Studio 步骤 ③ 也可勾选「本机预处理 / 逐段 ASR」，无需改 `.env`。

### B. 云端一键编排（远端预处理，legacy）

上传整段 wav → 远端 `train.sh`（切分 + FunASR + spike）→ 拉回权重。适用于本机 ASR 不可用或需与 WebUI 完全一致的 FunASR 对齐。

### C. 外部训练后导入

- Studio 上传：`POST /api/v1/voices/import-weights/upload`
- 本机路径：`POST /api/v1/voices/import-weights` 或 `scripts/import_engine_weights.py --from-result-json`

共享注册：`domains/voices/weight_registration.py`
