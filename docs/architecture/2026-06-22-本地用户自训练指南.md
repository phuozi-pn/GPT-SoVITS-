# 本地用户自训练与真实试听

**日期**: 2026-06-22  
**适用**: Windows 本机 + GPT-SoVITS Docker（9880 api_v2）

## 三种训练模式

| `TRAIN_MODE` | 说明 | 需要 |
|--------------|------|------|
| `mock`（默认） | 占位版本，合成蜂鸣 | 无 |
| `quick` | **快速克隆**：用上传干声作参考，真实引擎 zero-shot | `ENGINE_MOCK=false` + 9880 |
| `engine` | 完整 GPU 微调 | `ENGINE_TRAIN_ROOT` + Docker GPU |

`TRAIN_MODE=auto`（推荐）：`TRAIN_MOCK=false` 且无引擎目录时自动选 `quick`。

## 本机真实音色（推荐起步）

### 1. 启动引擎

```powershell
# GPT-SoVITS 容器（另开终端保持运行）
cd C:\Users\panta\Desktop\GPT-SOVITS\GPT-SoVITS
docker compose run --service-ports --remove-orphans GPT-SoVITS-CU128-Lite

# 同步 .env
cd C:\Users\panta\Desktop\GPT
.\scripts\engine_sync_env.ps1
```

### 2. 配置 `.env`

```env
TRAIN_MOCK=false
TRAIN_MODE=quick
ENGINE_MOCK=false
QC_DEV_RELAX_DURATION=true
QC_DEV_MIN_DURATION_SEC=3
KYC_MOCK=true
CONSENT_AUTO_APPROVE=true
```

### 3. 启动平台

```powershell
.\scripts\platform_start.ps1 -Background
.\scripts\web_dev.ps1
```

### 4. Web 流程

1. 打开 `/studio`（训练工作台）
2. 顶栏应显示「快速克隆：使用你的干声作为参考…」
3. ① 创建音色 → ② 上传 wav + 参考文本 → ③ 训练 → ④ 合成试听

可用样本：`infra/engine/samples/ref_zh_zero_shot.wav`

### 5. Smoke

```powershell
python scripts/smoke_w2_upload_train.py
# 需 TRAIN_MOCK=false TRAIN_MODE=quick，且 ENGINE_MOCK=false 时再测合成
```

## 完整 GPU 微调

见 [云端 GPU 训练指南](./2026-06-10-云端GPU训练指南.md)。

### 路径 A：Studio 云端一键（推荐）

1. `.env` 设置 `TRAIN_MOCK=false` 与 `ENGINE_TRAIN_ROOT`（拉回权重后本机合成）
2. `/studio` 步骤 ③ 选「云端完整微调」→ 填写 AutoDL SSH → 保存并验证
3. 上传干声后开始训练，平台自动 SCP → 远端 `train.sh` → 拉回权重

### 路径 B：手动云端训练后导入

在 GPU 服务器跑完 `train.sh` 后，Studio 选「导入外部权重」或 `scripts/import_engine_weights.py`。

### 路径 C：本机 Docker GPU

```env
TRAIN_MOCK=false
TRAIN_MODE=engine
ENGINE_TRAIN_ROOT=C:/Users/you/Desktop/GPT-SOVITS/GPT-SoVITS
ENGINE_TRAIN_DOCKER=<容器名>
```
