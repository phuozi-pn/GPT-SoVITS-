# 快速克隆与素材预处理指南

| 日期 | 2026-06-27 |
|------|------------|
| 适用 | Studio `/studio` · `TRAIN_MODE=quick` · api_v2 9880 |

## 1 快速克隆是什么

快速克隆（`train_mode=quick_clone`）**不做 GPU 微调**，只用用户上传的干声 **前 3–9 秒** 作为 api_v2 zero-shot 的参考音频（`ref_audio` + `prompt_text`），立即得到可合成版本。

与云端完整微调对比见 [云端训练 MVP](./2026-06-22-云端训练一键编排-MVP.md#与快速克隆对比)。

## 2 两类文本（勿混用）

| 字段 | 含义 | 要求 |
|------|------|------|
| **参考文本**（步骤 ②） | 参考音频里**实际说的话** | 与 3–9 秒 ref **逐字对齐** |
| **试听台本**（步骤 ④） | 要合成的新内容 | 任意句子，可与参考文本不同 |

常见故障：参考文本写了整段长稿，但引擎只裁前 9 秒 → 音文错位 → 糊、乱、像「电音/串词」。

平台行为（2026-06-27 起）：

- 上传后 ASR 默认识别**前 9 秒**（`ASR_CLIP_SEC=9`）
- 快速克隆 Job 在裁好 `ref.wav` 后会对**该片段再 ASR 一次**，写入版本 `ref_text`
- Studio 点「使用 9 秒干声样本」会**清空 sessionStorage 工作区**，避免复用旧 `voiceVersionId`

## 3 摸底样本（标准干声）

| 资源 | 路径 |
|------|------|
| 9 秒 wav | `infra/engine/samples/keyword_vocal_9s.wav` |
| 参考文本 | `infra/engine/samples/keyword_vocal_9s_ref.txt` |
| 生成脚本 | `scripts/prep_studio_dry_vocal_clip.py --copy-public` |

Studio 步骤 ② 点 **「使用 9 秒干声样本」** → 从步骤 ① 新建音色走一遍，勿复用懒羊羊等测试音色 ID。

## 4 带 BGM 素材：人声分离

平台**不提供**视频轨分离 UI；本地预处理推荐：

```powershell
cd C:\Users\panta\Desktop\GPT
python scripts\separate_vocals_demucs.py "输入文件夹" -o "输出_vocals"
```

- 依赖：`pip install demucs soundfile`、本机 `ffmpeg`
- 输出 `*_vocals.wav` 再裁 3–9 秒、转 32kHz 上传 Studio
- 动画/梗包素材注意 IP 合规，见 [合规红线](../../.cursor/rules/20-compliance-safety-redlines.mdc)

## 5 推理参数（减轻电音）

快速克隆版本默认写入**稳态预设**（`voice_platform/engine/infer_defaults.py`）：

| 参数 | 快速克隆默认 | 旧默认（易电音） |
|------|-------------|------------------|
| temperature | **0.68** | 0.78 |
| speed_factor | **1.0** | 1.05 |
| top_p | **0.95** | 1.0 |

Studio 步骤 ④ 滑条与上述一致。已有版本批量修补：

```powershell
python scripts\apply_tune_preset.py --all-real --stable
```

仍电音时优先排查：**BGM 残留**、参考文本不对齐，再将温度手动降到 0.6–0.65。

## 6 开发环境清理

```powershell
# 预览将删除的测试音色
python scripts\prune_dev_voices.py
# 执行删除（懒* 测试壳、污染 ref_text、空壳「我的音色」等）
python scripts\prune_dev_voices.py --apply
```

报告：`.runtime/voice_cleanup_report.json`

## 7 推荐流程（臭名 / 短句包）

1. `separate_vocals_demucs.py` 分离人声  
2. `ffmpeg -i xxx_vocals.wav -t 9 -ac 1 -ar 32000 ref_9s.wav`  
3. Studio：① 新建音色 → ② 上传 + 参考文本（与 9 秒一致）→ ③ 快速克隆 → ④ 试听  
4. 听感差 → 换更干净片段或走 [云端 GPU 训练](./2026-06-10-云端GPU训练指南.md)

## 9 故障速查

| 现象 | 处理 |
|------|------|
| 摸底像被「污染」 | 清空浏览器 `studio_workspace_v1` / 无痕窗口；点样本后从步骤 ① 新建音色 |
| 我的音色 500 | 确认 `domains/voices/service.py` 已 import `resolve_asset_preview_audio_url` |
| 合成空 / 500 | 刷新页面；查 `infer.log`、9880 是否存活 |
| 电音重 | 稳态参数 + 干净干声；避免带 BGM 原包 |
| ref 乱码 | 勿信带 BGM 素材的 ASR；手动填与音频一致的台词 |
