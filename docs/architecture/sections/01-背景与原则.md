## 1.2 业务目标

在 **4 周**内交付可内测的 **短剧配音工作台**，验证闭环：

```text
授权 → 素材质检 → 训练 → 单条/批量合成 → 合规导出
```

| 维度 | 目标 |
|------|------|
| 技术 | ~10min 干声可训；训练+合成 Job 可观测 |
| 工作流 | 项目 → 角色 → CSV → 分轨 ZIP |
| 合规 | 授权书、敏感词、AI 告知、显式标识不阻断主路径 |
| 引擎 | GPT-SoVITS **v2Pro**，`model_tag = gsv-v2pro-20250606` |

**一句话架构**：自研平台层（API + 合规 + 工作流）+ 容器化 v2Pro Worker，**引擎与平台分离、合规不可绕过**。

---

## 1.3 架构原则

| # | 原则 | 落地要求 |
|---|------|----------|
| P1 | 引擎与平台分离 | 合规/CSV/配额不进模型仓库；API 无 CUDA |
| P2 | 引擎版本 pinned | 训练与推理同一 `model_tag` |
| P3 | 最小 fork | Worker 调 upstream；升级 = 换镜像 tag |
| P4 | 合规不可绕过 | [ComplianceGateway](./04-运行时与集成.md#44-compliancegateway) 统一门禁 |
| P5 | 4 周可交付 | 单 GPU 分时；扩展点预留、实现分波次 |

---

## 1.4 约束 → 推论

| 约束（宪章/SRS） | 架构推论 |
|------------------|----------|
| 4 周 MVP-0 | 单体多模块；不强制 K8s |
| 合规不可砍 | 独立 Gateway + 导出单通道 |
| ~10min 普通干声 | v2Pro；训练前 QC |
| 短剧 CSV 主路径 | Production 上下文；W2 波次交付 |
| MVP+1 市场 | Marketplace 上下文占位 |
| 小团队 | FastAPI + Redis + PG + OSS |

---

## 1.5 设计目标优先级

冲突时按序取舍：

1. **合法可交付**（授权、标识、敏感词）
2. **技术闭环**（训练 + 合成 Job 成功）
3. **短剧效率**（CSV 批量）
4. **运维与扩展成本**
5. **极致性能 / 多引擎**（MVP+1）

---

## 1.6 核心思路（五条）

1. **六层逻辑架构** + **有界上下文**，避免巨石单体。
2. **GPU Worker 容器化**，故障隔离。
3. **ComplianceGateway** 前置，Worker 不判合规。
4. **统一 Job 模型** + `trace_id`。
5. **现在与未来分离**：MVP-0 单卡分时 → MVP+1 Infer 池与市场域。
