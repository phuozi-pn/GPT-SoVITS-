## 3.2 MVP 实现波次

在宪章 14 条 P0 上，**实现顺序**可裁剪而不改架构：

| 波次 | 周 | 能力 | REQ |

**不可砍（架构层）**：003、009、021、010 — 须经 Gateway / 导出单通道。

## 3.3 代码仓库结构（MVP-0）

本仓库根目录（**W1 已落盘**）：

```text
GPT/
├── docs/
├── infra/                    # docker/ + engine/
├── apps/api/                 # FastAPI BFF ✅
├── domains/                  # auth, compliance, synthesis, training, jobs ✅
├── voice_platform/           # job, auth, quota, storage, config ✅
└── workers/infer, workers/train ✅
```

**引擎不在本仓库**：上游 `GPT-SoVITS` clone + [Docker Hub 官方镜像](../../../infra/engine/README.md)。

> 勿使用 Python 包名 `platform`；横切层包名为 **`voice_platform`**。根目录 `platform/README.md` 仅为说明。

**依赖纪律**：

- `domains/*` ↛ `workers/*`
- `workers/*` → 仅 `voice_platform/job` 契约 + storage
- `api` → 应用服务协调 `domains`
