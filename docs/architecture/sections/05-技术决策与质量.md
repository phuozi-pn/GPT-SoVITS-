## 5.1 技术选型

| 维度 | MVP-0 | 备选 | 理由 |
|------|-------|------|------|
| API | **FastAPI** | Go | 与算法同栈 |
| 前端 | **Vue 3** | React | 表单/表格场景 |
| 队列 | **Redis** | PG 轮询 | 低延迟、组件少 |
| DB | **PostgreSQL 15+** | — | 事务、JSON、审计 |
| 存储 | **境内 OSS** | MinIO | 合规不出境 |
| 引擎 | **v2Pro pinned** | v3/v4 | 见 ADR-001 |

## 5.2 架构决策记录（ADR）

### ADR-001：引擎 v2Pro

| 考量 | v2Pro | v3/v4 |
|------|-------|-------|
| ~10min 干声 | 可训 | 素材更挑剔 |
| 相似度 | SV 嵌入 | zero-shot 路线不同 |
| 推理速度 | ≈ v2 | 不可预期 |
| VRAM | Spike 单样本 **~6.5GB**；生产 8–10min 估 **~12GB** | — |
| 4 周成本 | 单引擎线 | 多 Worker 线 |

**拒绝**：Gradio 生产化；MVP 默认 v3/v4；深度 fork `models.py`。

**工程**：32kHz；SV 权重见 [Spike](../2026-06-03-w1-spike-v2pro-快速验证.md)。

### ADR-002：不用 Gradio 作生产 UI

- **决策**：自研 Web + Job 状态。
- **代价**：上传/进度自研；**收益**：多租户与合规。

### ADR-003：合规导出单通道

- **决策**：对外下载仅 PostWorker 产物。
- **代价**：多 ffmpeg Job；**收益**：100% 显式标识可审计。

### ADR-004：引擎 Docker Hub 官方镜像 {#adr-004-引擎-docker-hub-官方镜像}

| 维度 | 说明 |
|------|------|
| **决策** | W1 Spike 与 Worker 基础镜像优先用 **Docker Hub 官方 GPT-SoVITS 镜像**（Miniconda + CUDA + WebUI），非从零 `pip install`。 |
| **服务** | `GPT-SoVITS-CU126-Lite`（= `latest`）、`CU128-Lite`、`CU126`、`CU128`。 |
| **理由** | 5080 等新卡 CUDA 12.8 路径清晰；与上游 CI 一致；Spike 省环境排查时间。 |
| **取舍** | 镜像体积大 ↔ 环境 reproducible；生产仍 **pinned digest + tag `20250606v2pro`**。 |
| **自研** | 本仓库 `workers/train|infer` 仅 **Adapter**；compose 在上游目录执行，见 [infra/engine/README.md](../../../infra/engine/README.md)。 |
| **拒绝** | 在平台仓库内复制整套 GPT-SoVITS 源码；生产直接用 Gradio 对外。 |

## 5.4 非功能需求

| NFR | 目标 | 手段 |
|-----|------|------|
| 可用性 | API 99% 内测 | 健康检查；Job 重试 1 次 |
| 性能 | 登录 P95 <500ms | API 不阻塞 GPU |
| 安全 | 私有 OSS + 签名 URL | TTL 15min |
| 审计 | 登录/授权/导出 | append-only `audit_log` |
| 合规 | 数据境内 | 固定 region |
| 可维护 | 引擎升级 | 换 Worker 镜像 |
