## 7.2 风险与缓解

| # | 风险 | 缓解 |
|---|------|------|
| R1 | 单 GPU 瓶颈 | MVP 接受；MVP+1 Infer 池 |
| R2 | 训练失败率高 | QC + Spike 超参 + 结构化错误 |
| R3 | Worker OOM 拖 API | 容器隔离；API 无 torch |
| R4 | raw 下载漏洞 | ADR-003 + 集成测试 |
| R5 | 需求膨胀 | Core→Workflow→Export 波次 |
