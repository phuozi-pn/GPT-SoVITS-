# 制作场景三分法：短剧 · 情景 · 演唱

版本：v1.0 · 2026-06-19  
关联：[Web 工作流与页面地图](../architecture/2026-06-16-web-frontend-工作流与页面地图.md) · [模块 E 项目与 CSV](./modules/2026-06-01-module-E-项目角色与CSV.md) · [模块 F 合成与导出](./modules/2026-06-01-module-F-合成与导出.md)

## 1. 产品定位

「制作」模块面向三类内容生产场景，共用 **音色资产 + 分段合成 + 合规导出**，但输入形态、分段规则与批量策略不同：

| 场景 | 用户目标 | 典型输入 | 主入口 |
|------|----------|----------|--------|
| **短剧文本配音** | 成百上千行台词批量出片 | CSV（角色,台词） | `/projects` |
| **多人对话情景配音** | 一段剧本多角色对话，快速返听 | 剧本文本 / AI 分段 | `/library`（情景模式） |
| **歌曲分段多音色演唱** | 歌词按句/段指派不同声线 | 歌词 + 段落角色 | `/library`（演唱模式，规划中） |

三者不是三个独立产品，而是 **同一合成引擎上的三种工作模式**。

## 2. 现状对照（2026-06-19）

### 2.1 短剧文本配音 — 已有主干

| 能力 | 状态 | 代码/文档 |
|------|------|-----------|
| 项目 + 角色绑定音色 | ✅ | `ProjectView` · 模块 E |
| CSV 批量合成、行级失败隔离 | ✅ | `submitBatchCsv` · 架构 4.1.3 |
| 合规 ZIP 导出 | ✅ | 模块 F |
| 产品文案显式「短剧」 | ⚠️ 弱 | 侧栏仍写「批量配音」 |

**缺口（Should）**

- 侧栏/首页用「短剧批量配音」替代含糊的「批量配音」
- CSV 模板与示例短剧剧本（已有 `batch_template.csv`，需文档链到场景说明）
- 单项目多批次、集数/场次元数据（Could，W2+）

### 2.2 多人对话情景配音 — 已有核心，需产品化命名

| 能力 | 状态 | 代码/文档 |
|------|------|-----------|
| `角色：台词` / `【角色】` 等格式解析 | ✅ | `parseScreenplayScript` |
| 卡司持久化、同角色批量改音色 | ✅ | `characterCast.ts` · `CastProfileBar` |
| DeepSeek AI 智能分段 | ✅ | `domains/script` · `ScriptEditor` |
| 多音色 `segments[]` 一次合成拼接 | ✅ | `buildSynthesisPayload` · infer worker |
| 分段级语速/温度/音高 | ✅ | `SegmentBlock` |
| UI 入口命名 | ⚠️ | 工具栏写「情景配音」，首页/导航未统一 |

**缺口（Should）**

- `/library` 默认引导：粘贴剧本 → 开「情景模式」→ 卡司指派
- 旁白/内心独白/环境音角色模板（Could）
- 从情景会话 **导出为 CSV** 进入短剧批量线（Could，打通两场景）

### 2.3 歌曲分段多音色演唱 — 未实现，需单独立项

| 能力 | 状态 | 说明 |
|------|------|------|
| 歌词行解析（主唱/和声/段落） | ❌ | 无 `parseLyricsScript` |
| 旋律/曲谱跟随 | ❌ | GPT-SoVITS 为 **说话** TTS，非歌声合成 |
| 分段多音色 | ⚠️ 仅台词级 | 现有 `segments` 可复用数据结构 |
| 音高 `pitch_factor` | ⚠️ 后处理变调 | `pitch_shift_wav`，非演唱质感 |

**技术结论**

- **近期可做（MVP+1）**：歌词按行分段 + 多音色「念唱/说唱式」预览（明确标注非专业歌声，合规告知）
- **中期（Spike）**：接入歌声转换（SVC / DiffSinger 等）或旋律参考音频
- **训练素材**：歌声克隆需歌唱干声授权，合规红线与说话素材分开审核

## 3. 信息架构建议

制作侧栏保持 **两个路由**，用 **模式** 区分情景/演唱，避免导航膨胀：

```
制作
├── 智能配音工作台  /library
│     ├── 单人朗读（默认）
│     ├── 多人情景配音（multiMode）
│     └── 歌曲分段演唱（planned: vocalMode）
└── 短剧批量配音    /projects
```

访客首页「标准工作流」改为「三大制作场景」卡片，与上表对齐。

## 4. 用户故事（摘要）

### US-PROD-01 短剧批量

> 作为短剧制片，我上传 CSV（角色,台词），系统按角色映射音色批量合成，失败行可重试，最终下载合规 ZIP。

**验收**：与现有 `test_synthesis_api` / 批量 smoke 一致；文案含「短剧」。

### US-PROD-02 多人情景

> 作为配音导演，我粘贴剧本，AI 或规则自动分出角色行，为每个角色指定音色，一键合成整段对话。

**验收**：方源/白凝冰类剧本分段正确；卡司记忆；多段 `segments` 合成一条音频。

### US-PROD-03 歌曲分段（规划）

> 作为音乐创作者，我粘贴歌词并为每段指定演唱者音色，生成多声部预览；专业歌声需旋律参考或歌声引擎。

**验收（Phase 1）**：歌词行解析 + 多音色合成 + 产品内标注「实验性念唱」  
**验收（Phase 2）**：旋律跟随试听（依赖引擎 Spike）

## 5. MoSCoW

| 优先级 | 项 |
|--------|-----|
| **Must** | 维持短剧 CSV 与情景多段合成稳定；导航/文案体现三分法 |
| **Should** | 情景模式 onboarding；短剧 CSV 模板文档化；情景 → CSV 导出 |
| **Could** | 歌词解析 + 念唱模式；和声/副歌标记 |
| **Won't（MVP+0）** | 宣称「专业 AI 歌声」而无旋律引擎支撑 |

## 6. 合规提示

- 三类场景均须 **已授权声纹**；歌曲克隆需明确歌唱授权范围
- 合成产物 **AI 生成标识** 不可省略（模块 B/G）
- 禁止未授权名人声线模仿演唱（见合规红线规则）
