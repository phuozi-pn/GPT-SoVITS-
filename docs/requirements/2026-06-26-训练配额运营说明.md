## 1 计量口径

| 类型 | 何时 +1 | 存储 |
|------|---------|------|
| **TTS Token** | 合成 Job `succeeded` 后，按文本 Unicode 码点数（含标点）；**对外称 Token，MVP 阶段 1 Token = 1 码点** | `usage_records`，`record_type=chars` |
| **训练次数** | 以下任一成功即计 1 次：云端/快速克隆训练 Job `succeeded`、**导入外部权重**成功 | `usage_records`，`record_type=train` |

计费月为 **自然月（Asia/Shanghai）**，每月 1 日 0 点重置已用统计；用户表上的限额覆盖字段不受重置影响。

## 2 默认限额（环境变量）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `QUOTA_MONTHLY_CHAR_LIMIT` | 20000 | 全站默认月 TTS Token 上限（内部字段名仍为 char） |
| `QUOTA_MONTHLY_TRAIN_LIMIT` | 1 | 全站默认月训练次数上限 |

未在 `users` 表单独配置的用户，使用上述默认值。

## 3 套餐档位（运营参考）

内测阶段不设自动计费，运营在后台按档位 **手工调额**。档位数值与调研草案一致，见前端 `apps/web/src/constants/quotaTiers.ts`：

| 档位 | 月 TTS Token | 月训练次数 | 典型用户 |
|------|------------|------------|----------|
| 免费 | 20,000 | 1 | 试用 / 学生 |
| 创作者 | 500,000 | 5 | 独立 UP、兼职配音 |
| 团队 | 3,000,000 | 20 | 短剧工作室 |

保存前可在弹窗内微调具体数字。

## 4 运营调额 SOP

### 4.1 为用户提升额度

1. 使用 **管理员账号** 登录（开发环境默认 `X-User-Id: bbbbbbbb-bbbb-bbbb-bbbb-bbbbbbbbbbbb`）。
2. 打开 **管理后台 → 用量报表**。
3. 找到目标用户（手机号 / 用户 ID 前 8 位）。
4. 点击 **调整限额**：
   - 点选 **免费 / 创作者 / 团队** 填入档位，或手动输入 Token 上限与训练上限。
   - **保存**。
5. 让用户刷新 Studio 页，顶部应显示新上限；`GET /api/v1/usage/quota` 同步返回。

### 4.2 API（脚本 / 自动化）

```http
PATCH /api/v1/admin/users/{user_id}/quota
X-User-Id: {admin_user_id}
Content-Type: application/json

{
  "monthly_char_limit": 500000,
  "monthly_train_limit": 5
}
```

仅传需要修改的字段；返回体为更新后该用户的 `QuotaSummary`。

### 4.3 用户反馈「训练按钮灰色」

1. 查用量报表：本月 `trainings_used` 是否已达 `monthly_train_limit`。
2. 若合理超额：按档位或个案调额。
3. 若未超额仍不可用：查 KYC、授权书、素材锁定等（非配额问题）。

### 4.4 用户反馈「合成 402」

1. 查 `chars_used` 与 `monthly_char_limit`。
2. 短剧批量合成前会预检总 Token 数；可临时提 Token 上限或等下月重置。

|------|------|
| `GET /api/v1/usage/quota` | 当前用户配额摘要 |
