# 从零安装指南（Windows）

在**新电脑**上从 Git 克隆到打开 Web 工作台的完整步骤。预计 **30–60 分钟**（含 Docker、Node 下载）。

> 所有命令在仓库根目录 **`GPT/`** 下执行（不要在上级 `Desktop/` 直接跑脚本）。

---

## 0. 你会得到什么

| 组件 | 端口 | 说明 |
|------|------|------|
| Web 工作台 | 5173 | Studio / 音色库 / 批量配音 |
| 平台 API | 8001 | REST + OpenAPI |
| PostgreSQL + Redis | Docker | 数据与任务队列 |
| GPT-SoVITS 合成（可选） | 9880 | 真实 AI 配音，需 NVIDIA GPU |

**推荐分工**：本机跑平台 + Web + 合成；**完整音色微调**在 [云端 GPU](2026-06-10-云端GPU训练指南.md) 完成。

---

## 1. 安装基础软件

按顺序安装（均需勾选「加入 PATH」）：

| 软件 | 版本建议 | 下载 / 验证 |
|------|----------|-------------|
| **Git** | 最新 | https://git-scm.com/download/win → `git --version` |
| **Python** | 3.11 或 3.12 | https://www.python.org/downloads/ → 安装时勾选 *Add to PATH* → `python --version` |
| **Node.js** | 20 LTS+ | https://nodejs.org/ → `node -v` · `npm -v` |
| **Docker Desktop** | 最新 | https://www.docker.com/products/docker-desktop/ → 启用 **WSL2 后端** → 启动后 `docker --version` |

### 可选（真实 AI 合成）

| 软件 | 说明 |
|------|------|
| **NVIDIA 驱动** | `nvidia-smi` 有输出 |
| **Docker GPU** | Docker Desktop → Settings → Resources → 启用 GPU |

---

## 2. 克隆本仓库

打开 **PowerShell**（建议「以管理员身份」仅在你需要改系统路径时；日常开发普通窗口即可）：

```powershell
cd $env:USERPROFILE\Desktop

# SSH（已配置 GitHub 密钥）
git clone git@github.com:phuozi-pn/GPT-SoVITS-.git GPT

# 或 HTTPS
# git clone https://github.com/phuozi-pn/GPT-SoVITS-.git GPT

cd GPT
```

已有仓库时更新：

```powershell
cd C:\Users\你的用户名\Desktop\GPT
git pull origin main
```

---

## 3. Python 环境与依赖

```powershell
cd GPT
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 若 Activate 被策略拦截，先执行：
# Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

pip install -U pip
pip install -e ".[dev]"

copy .env.example .env
```

`.env` **首次可不改**，默认即可本地体验（Mock 训练 + Mock 合成）。

---

## 4. 启动平台（终端 1）

确保 **Docker Desktop 已运行**（托盘图标正常）。

```powershell
cd GPT
.\.venv\Scripts\Activate.ps1
.\scripts\dev_restart.ps1 -Background
```

等待约 30 秒，检查：

```powershell
.\scripts\platform_status.ps1
```

应看到 `api` / `train` / `infer` / `batch` 为 running。浏览器打开：

- http://127.0.0.1:8001/health → 应返回 JSON（含 `ok`）

若失败：

```powershell
cd infra\docker
docker compose -f docker-compose.dev.yml up -d
cd ..\..
.\scripts\platform_start.ps1 -Background
```

---

## 5. 启动 Web（终端 2）

**新开一个 PowerShell**，仍在 `GPT/`：

```powershell
cd GPT
.\scripts\web_dev.ps1
```

首次会自动 `npm install`。浏览器打开：

| 页面 | 地址 |
|------|------|
| 训练工作台 | http://127.0.0.1:5173/studio |
| 文本转语音 / 音色库 | http://127.0.0.1:5173/library |
| 批量配音 | http://127.0.0.1:5173/projects |
| 音色馆 | http://127.0.0.1:5173/catalog |
| API 文档 | http://127.0.0.1:8001/api/v1/docs |

开发模式默认 **跳过登录**（`.env` 中 `DEV_SKIP_AUTH=true`）。

---

## 6. 第一次使用（Mock 模式，无需 GPU）

1. 打开 **Studio** → 创建音色 → 勾选授权 → 上传一段 **3 秒以上** wav/mp3  
2. 确认质检 → 点击训练（`TRAIN_MOCK=true` 时几秒完成）  
3. 打开 **批量配音** → 新建项目 → 上传 `apps/web/public/samples/batch_template.csv` 试跑  

此阶段合成是占位音频，用于验证**流程**是否正常。

---

## 7. 开启真实 AI 合成（可选，需 GPU）

### 7.1 克隆上游引擎

与 `GPT` **同级**目录：

```powershell
cd $env:USERPROFILE\Desktop
git clone https://github.com/RVC-Boss/GPT-SoVITS.git GPT-SOVITS\GPT-SoVITS
cd GPT-SOVITS\GPT-SoVITS
git checkout 20250606v2pro
```

目录应类似：

```text
Desktop/
├── GPT/                    ← 本平台
└── GPT-SOVITS/
    └── GPT-SoVITS/         ← 上游引擎
```

详细镜像与权重说明见 [infra/engine/README.md](../../infra/engine/README.md)。

### 7.2 启动 9880 合成服务

```powershell
cd $env:USERPROFILE\Desktop\GPT
.\scripts\engine_api_v2.ps1 -Action start
.\scripts\engine_api_v2.ps1 -Action status
```

### 7.3 修改 `.env`

```ini
ENGINE_MOCK=false
ENGINE_TTS_URL=http://127.0.0.1:9880
ENGINE_TRAIN_ROOT=C:/Users/你的用户名/Desktop/GPT-SOVITS/GPT-SoVITS
```

路径用 **正斜杠** `/`，把 `你的用户名` 换成实际 Windows 用户名。

### 7.4 重启平台 Worker

```powershell
.\scripts\dev_restart.ps1 -Background
```

在 **音色库** 选已导入的音色 → 合成，应听到真实 AI 语音。

### 7.5 使用云端训练的音色

在 AutoDL 等 GPU 上微调后，权重 scp 到本机 `ENGINE_TRAIN_ROOT`，再执行：

```powershell
.\.venv\Scripts\python.exe scripts\import_engine_weights.py
```

详见 [云端权重接入 Web 合成](2026-06-14-云端权重接入Web合成.md)。

## 8. 停止服务

```powershell
cd GPT
.\scripts\platform_stop.ps1
.\scripts\engine_api_v2.ps1 -Action stop   # 若开过引擎
```

Web 终端 `Ctrl+C`。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| `无法加载 Activate.ps1` | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `web_dev` 报 API 不可达 | 先 `dev_restart.ps1 -Background`，确认 Docker 已开 |
| `docker compose` 失败 | Docker Desktop 完全退出后重开；检查 WSL2 |
| 端口 8001 / 5173 占用 | 改 `.env` 中 `STORAGE_PUBLIC_BASE_URL` 端口，或结束占用进程 |
| 合成无真实声音 | 检查 `ENGINE_MOCK=false`、9880 `status` 正常 |
| 训练一直是 Mock | 正常；真微调用 [云端 GPU 训练指南](2026-06-10-云端GPU训练指南.md) |
| `pip install` 很慢 | 使用国内 PyPI 镜像或代理 |
